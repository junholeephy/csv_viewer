# Business Rules — csv-viewer

## Dialect / Parsing
- **R-D1** RFC 4180: 행 종결자 LF·CRLF. 따옴표 안 `""` 는 따옴표 하나. 따옴표 안의 줄바꿈·구분자는 데이터. 단독 CR 종결자는 미지원(그런 파일은 행 경계가 다르게 보일 수 있음 — 알려진 제약).
- **R-D2** 따옴표는 필드 시작에서만 인용을 연다. 필드 중간의 따옴표, 닫는 따옴표 뒤의 문자는 리터럴 (Python `csv` 기본 방언과 동일).
- **R-D3** 구분자는 `, \t ; |` 중 하나(1바이트 ASCII). 사용자가 사이드바에서 덮어쓸 수 있다.
- **R-D4** 지원 인코딩: `utf-8-sig`(UTF-8 포함), `cp949`, `euc-kr`, `latin-1`. ASCII 투명하지 않은 인코딩(UTF-16 등)은 미지원.

## Rows
- **R-R1** 완전히 빈 줄은 데이터 행이 아니다. 인덱서·리더 모두 동일 규칙. 공백만 있는 줄은 1개 필드짜리 행이다.
- **R-R2** 행 번호는 비어 있지 않은 데이터 행 기준 1-based. 헤더는 0번이 아니라 행 번호에 포함되지 않는다.
- **R-R3** 열 수 불일치: 모자라면 결측, 넘치면 `…extra` 컬럼에 구분자로 이어 붙임. `⚠` 컬럼에 "열 실제/기대" 표시, 페이지 경고에 개수.

## Header
- **R-H1** 첫 번째 비어 있지 않은 행이 헤더. 앞뒤 공백 제거. 빈 이름 → `col_<1-based 위치>`. 중복 → 두 번째부터 `name.1`, `name.2` (그 이름도 이미 있으면 번호 증가).
- **R-H2** 헤더만 있는 파일: 컬럼 목록 표시 + "데이터 행 없음".

## Types / Display
- **R-T1** 결측 판정은 `schema.NULL_TOKENS` (`"" NA N/A null NULL None -`, 앞뒤 공백 무시).
- **R-T2** 타입은 페이지 내 비결측 값 **전부**가 해석될 때만 부여. 순서 int → float → bool → datetime → str. UI 에 "현재 페이지 기준" 명시.
- **R-T3** 숫자 표시: 천 단위 구분, float 은 소수점 최대 4자리(뒤 0 제거). "원본 보기" 토글 시 원본 문자열 표.
- **R-T4** 결측 셀은 배경색 하이라이트 (라이트/다크 모두 식별 가능한 색).
- **R-T5** 정렬은 `st.dataframe` 헤더 클릭, 현재 페이지 한정.

## Paging
- **R-P1** page_size ∈ {50, 100, 500}, 기본 100. 바꾸면 현재 첫 행이 포함된 페이지로 이동 (`page = first_row // new_size`).
- **R-P2** 첫 페이지는 인덱스 없이 표시.
- **R-P3** 인덱싱 중에는 체크포인트가 존재하는 페이지까지만 이동 가능. 페이지 입력 최댓값 = `max_reachable_page`. "끝" 버튼은 인덱스 완료 후 활성화.
- **R-P4** 파일·인코딩·구분자 변경 시 page = 0, 이전 IndexJob 중단.
- **R-P5** 파일 mtime/size 가 바뀌면(재선택·rerun 시 감지) 캐시 키가 달라져 새 인덱스.

## Files
- **R-F1** 목록은 `--root` 하위 `*.csv`, `*.tsv`, `*.txt` (재귀, 숨김 디렉터리 제외, 정렬). 상대 경로로 표시.
- **R-F2** 선택 경로를 resolve 한 결과가 root 밖이면 거부(심볼릭 링크 포함).

## Errors (앱은 죽지 않는다)
| 상황 | 동작 |
|---|---|
| 0바이트 파일 | info "빈 파일" |
| 파일 없음/권한 없음/읽는 중 사라짐 | error 메시지 + 파일 재선택 유도 |
| 디코딩 오류 | `U+FFFD` 대체 + 경고 "디코딩 오류 n건 — 인코딩 변경 고려" (n = 페이지 내 `U+FFFD` 개수, 원본에 실제 U+FFFD 가 있으면 과대계상 — 알려진 근사) |
| 인덱싱 스레드 예외 | 진행 영역에 error, 이미 만든 체크포인트 범위 내 이동은 계속 허용 |
| `csv.Error` (필드 크기 한도 초과 등) | 해당 페이지 error, 다른 페이지 이동 가능. 필드 한도는 `csv.field_size_limit` 를 충분히 크게 설정 |
| `--root` 가 없음/디렉터리 아님 | 앱 상단 error 후 중단 |

## Data Privacy (스캐폴드 C3 해석)
- **R-S1** 화면 표시는 허용. 값은 로그·stdout·파일로 쓰지 않는다 (예외 메시지에 셀 값 포함 금지).
